# Security policy

## Supported versions

Security fixes are made on `main`.

## Reporting

Do not report vulnerabilities in public issues, discussions, or pull requests. Submit a private advisory at <https://github.com/tsrman/sthub-oss/security/advisories/new> with the affected version or commit, impact, reproduction, and suggested mitigation. Do not include real credentials.

We aim to acknowledge valid reports within 7 days. We will investigate, coordinate a fix and disclosure timeline with the reporter, and ask that details remain private until coordinated disclosure.
